# 🧬 Engenharia Reversa Assistida por IA - Clone Blobmaker

## 📝 Descrição do Projeto
Este projeto apresenta um estudo de **Engenharia Reversa** focado na replicação funcional e estética do site [Blobmaker.app](https://www.blobmaker.app/), um editor de formas SVG orgânicas. O desafio consistiu em clonar a interface e as funcionalidades do sistema sem visualizar o código-fonte original, transferindo o esforço da escrita sintática para a **descrição lógica e funcional** mediada por ferramentas de IA.

O projeto não apenas entrega um protótipo funcional, mas também serve como base para uma análise crítica sobre o impacto das IAs no desenvolvimento de software e os dilemas éticos da clonagem digital.

## 🚀 Competências e Metodologia
A execução deste projeto exigiu o desenvolvimento de novas competências indispensáveis para o cenário de "Desenvolvimento Assistido por IA":
* **Curadoria Crítica:** Validação incremental da estrutura de pastas e do layout base para garantir a qualidade técnica da solução.
* **Descrição Lógica e Visão Sistêmica:** Domínio da orquestração de regras de execução e mapeamento funcional para guiar a IA de forma precisa.
* **Foco na Experiência (UX/UI):** Priorização da responsividade e da "vibe" visual desde a fase inicial do mapeamento.

## 🛠️ Tecnologias e Ferramentas
* **Plataforma Base:** [Blobmaker](https://www.blobmaker.app/) (Original).
* **IA de Suporte:** Google Gemini / LLMs generativas para suporte à lógica de código.
* **Prototipagem:** Desenvolvimento de Single Page Application funcional com foco em renderização de vetores (SVG).

## 📊 Reflexão Ética e Profissional
O projeto aborda profundamente o limite entre a ferramenta de aprendizado e o plágio digital:
* **Dilema Ético:** A engenharia reversa torna-se plágio quando a clonagem fiel é usada comercialmente sem inovação incremental.
* **Diretriz Proposta:** O desenvolvedor deve utilizar a estrutura mapeada apenas como um "esqueleto" técnico, transformando o clone em uma **base autoral** através de melhorias reais e originalidade criativa.
